🏗️ Definición de Paquetes de Construcción (CWP)

Define los paquetes de construcción (CWP) del CWA-05 seleccionando disciplinas y distribuyendo horas hombre. Cada disciplina seleccionada se convertirá en un CWP con código automático.

Instrucciones Generales

Objetivo: Para el CWA-05 (Planta de Reactivos), debes:

1. Seleccionar disciplinas: Desde el listado disponible, elige cuáles forman parte de este área de construcción.

2. Estimar horas hombre: Del informe de fase anterior se estiman 184,050 HH totales para CWA-05. Distribuye esta cantidad entre las disciplinas seleccionadas según importancia relativa de cada una.

3. Codificar CWP: Cada paquete debe tener un código único siguiendo la estructura estándar. Tú debes definir los códigos de cada paquete.

4. Completar fichas: Cada CWP generado debe incluir: nombre de disciplina, código, CWA asociada (CWA-05), descripción detallada de alcances, HH estimadas, fecha de inicio y fecha de término.

Estructura de Codificación de CWP

Los paquetes de construcción deben codificarse siguiendo una estructura estándar. Analiza la siguiente tabla y crea los códigos para tus CWP:

Construction Work Package (CWP) - Estructura de Codificación
Nivel AWP Nº CWA Disciplina Nº Correlativo
C W P - 0 5 - C - 0 1
Pos 1 Pos 2 Pos 3 Pos 4 Pos 5 Pos 6 Pos 7 Pos 8 Pos 9 Pos 10 Pos 11
Cómo codificar:
• Pos 1-3: CWP (nivel de paquete)
• Pos 4: Separador (-)
• Pos 5-6: Número del CWA (05 para CWA-05)
• Pos 7: Separador (-)
• Pos 8: Código de Disciplina Propuesto (C, S, A, M, P, E, I, H, PR, o el que propongas)
• Pos 9: Separador (-)
• Pos 10-11: Número correlativo (01, 02, 03, etc.)

Ejemplo para CWA-05: CWP-05-C-01 (CWP del CWA-05, disciplina Civil, paquete 01)
